Introduction

Python is a high-level, interpreted programming language known for its readable syntax and gentle learning curve. It's widely used for web development, data analysis, automation, and scientific computing.

Unlike many languages that rely on curly braces, Python uses indentation to define blocks of code. This forces a consistent, clean style across every codebase you'll encounter.

These notes cover the core building blocks: variables, control flow, functions, and the data structures you'll reach for most often.

Installation

Most operating systems ship with some version of Python already installed. You can check which version is available by opening a terminal and running:

python3 --version

If Python isn't installed, download it from the official site and follow the installer for your platform. On Debian-based Linux systems, you can also install it directly from the package manager:

sudo apt install python3
  • Windows: use the official installer and check "Add to PATH"
  • macOS: comes pre-installed, or use Homebrew
  • Linux: usually available through your package manager
Variables and Data Types

Variables in Python don't require an explicit type declaration. The interpreter figures out the type based on the value assigned:

name = "Ada"
age = 36
height = 1.68
is_programmer = True

The most common built-in types you'll work with are:

  • str — text data
  • int and float — numeric data
  • bool — True or False values
  • list, tuple, dict, and set — collections

You can check a variable's type at any point using the built-in type() function.

Control Flow

Conditional statements let your program make decisions. Python uses if, elif, and else to branch logic:

if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teenager")
else:
    print("Child")

Loops let you repeat actions. The two most common are for loops, which iterate over a sequence, and while loops, which repeat as long as a condition holds true.

for i in range(5):
    print(i)
Functions

Functions let you package reusable logic behind a name. Define one with the def keyword:

def greet(name):
    return f"Hello, {name}!"

Functions can take default arguments, accept a variable number of parameters, and return multiple values packed into a tuple.

def add(a, b=10):
    return a + b

Keeping functions small and focused on a single task makes your code easier to test and reuse.

Lists and Dictionaries

A list is an ordered, mutable collection of items. You can add, remove, and access elements by index:

fruits = ["apple", "banana", "cherry"]
fruits.append("date")

A dict stores data as key-value pairs, which is useful when you need to look things up by name rather than position:

person = {"name": "Ada", "age": 36}
  • Use list when order matters
  • Use dict when you need fast lookups by key
  • Use set when you only care about unique values
Error Handling

When something goes wrong, Python raises an exception. You can catch these using a try/except block so your program doesn't crash outright:

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Can't divide by zero")

You can also use finally to run cleanup code regardless of whether an exception occurred, which is handy for closing files or network connections.

Catching overly broad exceptions can hide real bugs, so it's best to catch specific exception types whenever possible.
